# Agronavigator

Agronavigator — мобильное приложение на Flutter для сельскохозяйственной навигации.

Идея проекта появилась во время работы в сельском хозяйстве. Большинство существующих систем навигации стоят дорого и недоступны небольшим хозяйствам. Цель проекта — создать простое приложение, которое сможет выполнять основные задачи полевой навигации, используя обычный смартфон.

Проект находится в активной разработке и регулярно тестируется в реальных условиях.
Планируется провести полный цикл испытаний на осенних полевых работах, примерно 10-15 дней. 

---

## Что уже работает

- получение GPS-координат;
- преобразование GPS в локальную систему координат;
- отображение движения техники;
- построение обработанной площади;
- расчет площади поля;
- расчет урожайности;
- построение параллельных направляющих;
- инициализация GPS перед началом работы.

---

## Что планируется

- масштабирование рабочей области;
- перемещение карты;
- автоматический поворот по курсу движения;
- сохранение выполненных работ;
- сохранение полей;
- экспорт данных;
- поддержка RTK-приемников;
- отображение качества сигнала GPS.

---

## Почему создаётся этот проект

Я изучаю Flutter и мобильную разработку, создавая приложение, которое может пригодиться в реальной работе.

Во время разработки я использую современные инструменты, включая ИИ, однако все идеи, архитектура приложения, тестирование и проверка работы выполняются в процессе собственной разработки и полевых испытаний(на улице, при ходьбе, поездках и т.д).

Каждая новая функция сначала реализуется, затем проверяется во время реальных поездок и постепенно дорабатывается.
